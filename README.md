## What I do

Fullstack developer. I design and ship backend services, web UIs, and the infra that runs them.

I write APIs and async Python backends, React (and some Vue) frontends, and the glue between them: queues, databases, object storage, auth. I split systems into services, run them on Kubernetes or Docker Swarm, and own CI/CD so code actually reaches production.

AI agents handle routine work; service boundaries and review stay with me.
